# Power BI Dashboard

This folder contains the Power BI dashboard developed for the E-Commerce Sales & Customer Behaviour Analytics project.

## Dashboard

The dashboard provides interactive analysis of:

- Total Revenue
- Total Profit
- Profit Margin
- Total Customers
- Total Orders
- Sales by Category
- Profit by Category
- Monthly Sales Trend
- Orders by Payment Method
- Orders by Order Status
- Top 10 Products by Revenue

## Tools

- Microsoft Power BI
- Data Visualization
- Interactive Slicers
